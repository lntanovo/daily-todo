## 五项实现

1. 首屏：按需加载 CloudBase SDK、个人页、导入导出和 ZIP 模块；思源宋体按 Unicode 范围拆分，保留 Warm Paper 和三视图。可见首屏传输量超过建议的 30% 降幅，但登录完全可用时总下载量没有下降，见下节。
2. 专注：会话和统计由云端记录主导，修订号防止旧标签页覆盖；本机旧记录预览后幂等迁移，活动冲突由用户选择，本机原记录保留。
3. 重复任务：每日、每周指定星期和每月指定日；按日独立完成，月底缺失日期跳过。可读导出标记规则，普通重新导入提示不恢复规则。
4. 快速录入、云端模板及删除撤销：模板可套用、改名、删除；任务软删除后可即时撤销或在“最近删除”中跨会话恢复，关联完成和补充保留。
5. 完整 ZIP 备份：含八类表数据及可选私有背景；校验格式、数量、长度、SHA-256 与 ZIP 路径，预览后按类合并。数据库记录由单事务 RPC 恢复，同一备份重复恢复不重复写入。格式见 `完整备份格式.md`。

## 性能测量

测试条件：Edge 无头浏览器，390×844，禁用缓存，150ms RTT、1.6Mbps 下载、0.75Mbps 上传，每种场景 3 次取中位数。登录页公网 v1.3.4 基线：DOMContentLoaded 5513.8ms、FCP/LCP 1704ms、传输 1021869B（997.9KiB）、3 请求。公网 v1.4.0 可见首屏（不等 SDK 就绪）：DOMContentLoaded 1667ms、FCP/LCP 1684ms、传输 256208B（250.2KiB）、4 请求；相对基线 DOMContentLoaded 缩短约 69.8%，可见首屏传输下降约 74.9%。最终公网 v1.4.0 等待登录按钮可用后：DOMContentLoaded 1652.4ms、FCP/LCP 1648ms、总传输 1027444B（1003.4KiB）、5 请求；比旧版总传输多约 0.5%。因此只能说内容更早可见，不能说登录就绪后的总流量下降。没有真实用户样本，不宣称线上 p75 指标达标。已登录本地 fixture 基线：DOMContentLoaded 6485ms、FCP 260ms、LCP 284ms、传输 1202507B（1174.3KiB）、29 请求。v1.4.0 本地 fixture：DOMContentLoaded 6188.7ms、FCP 252ms、LCP 276ms、传输 1179585B（1151.9KiB）、27 请求，传输下降约 1.9%。本地开发服务和公网 CDN 不是同一环境，不直接比较两者。
