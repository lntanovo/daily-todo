# Warm Paper 完整备份格式 v1

扩展名为 `.zip`，在浏览器本地生成。它包含 `manifest.json`、`data.json`，有私有背景时还包含一个 `background.png` / `.jpg` / `.jpeg` / `.webp` / `.gif`。备份包含私人日程和图片，应保存在可信位置。

`manifest.json` 包含 `format: "warm-paper-backup"`、`version: 1`、导出时间、各表记录数、`data.json` 的 SHA-256，以及可选背景文件名、长度和 SHA-256。`data.json` 包含 `todo_tasks`（含软删除）、`todo_task_recurrences`、`todo_daily_completions`、`todo_completion_history`、`todo_daily_notes`、`todo_focus_sessions`、`todo_task_templates`、`todo_preferences` 八个数组。导出时移除账号 ID、密码、令牌和私有背景原存储路径；恢复时数据库以当前登录账号作为所有新记录的所有者。

恢复前检查 ZIP 文件大小、内部文件名、解压大小、格式版本、记录数和 SHA-256，并显示各类新增、相同及冲突数。首版仅提供合并恢复：按 ID/复合键跳过已有记录，不覆盖目标账号现有数据。除图片外，数据库记录由 `restore_todo_backup_v1` 在单个事务中恢复；重复导入幂等。背景文件在数据库事务之后单独上传，因此若背景上传失败，可再次导入。活动专注冲突时先由用户决定是否跳过备份中的活动计时。

编号文本、Markdown 和 Word 导入导出是可阅读清单，不是完整备份。重复任务导出会注明规则，作为普通任务重新导入时只创建单日任务，不恢复重复规则。格式升级时应新增版本解析器和迁移测试，不应静默接受未知版本。
