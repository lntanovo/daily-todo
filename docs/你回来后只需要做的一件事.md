# 你回来后只需要做的一件事

现在浏览器里应该有一个腾讯云登录或授权页面。

1. 用你自己的腾讯云账号登录。
2. 如果页面显示一个和终端相同的设备码，确认这是你刚才让 Codex 发起的网站部署登录。
3. 点击腾讯云页面自己的“确认授权”按钮。
4. 回到 Codex，告诉我“腾讯云授权完成”。

你暂时不需要购买服务器、域名或套餐，也不要把密码、短信验证码、SecretId、SecretKey 发给我。

授权完成后我会继续自动做：

- 确认或创建一个免费 CloudBase 环境；
- 打开邮箱登录、验证码注册和找回密码需要的配置；
- 创建任务与每日完成记录的数据库集合；
- 设置“每个人只能看自己的事项”的安全规则；
- 把当前页面接上云端，并保留第一次登录时迁移本地事项的通道；
- 部署并验证免费 HTTPS 网站地址。
